# Student Pass / Fail Predictor - React Frontend

Clean, modern React (Vite) interface for the Logistic Regression Student Result Predictor.

## Getting Started

1. **Install dependencies**:
   ```bash
   cd frontend
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173). The Vite dev server proxies requests from `/predict` to `http://127.0.0.1:8000/predict`.

3. **Build for production**:
   ```bash
   npm run build
   ```
   Output is generated in `frontend/dist/`.
